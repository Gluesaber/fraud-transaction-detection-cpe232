# Data

The competition data is **not included** in this repository (course-restricted, enrolled students only).

## Getting the real data
1. Join the Kaggle competition: https://www.kaggle.com/competitions/fraud-detection-cpe-232-data-models (access limited to the course).
2. Download `train.csv` and `test.csv` into a local folder, e.g. `data/raw/` (git-ignored).
3. Run the notebook with `DATA_DIR=data/raw`.

## Schema (train.csv)
| Column | Description |
|---|---|
| `id` | Row id |
| `time_ind` | Time step of the transaction (hours) |
| `transac_type` | CASH_OUT, TRANSFER, PAYMENT, CASH_IN, DEBIT (some missing) |
| `amount` | Transaction amount (some missing) |
| `src_acc`, `dst_acc` | Source / destination account ids (`M...` = merchant) |
| `src_bal`, `src_new_bal` | Source balance before / after (`src_bal` partly missing) |
| `dst_bal`, `dst_new_bal` | Destination balance before / after (`dst_bal` partly missing) |
| `is_flagged_fraud` | System flag for illegal attempts |
| `is_fraud` | **Target** (train only) |

Size: ~5.4M training rows, ~0.95M test rows; fraud is ~0.12% of transactions.

## Synthetic sample
`data/sample/` holds **synthetic** files with the same schema, generated by `scripts/make_sample_data.py`.
They contain no real data and exist only so the pipeline can run end to end
(`DATA_DIR=data/sample`). Model scores on them are not meaningful.
